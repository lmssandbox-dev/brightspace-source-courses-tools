## Version and lifecycle evidence

The native version-check contract is documented by [D2L API Properties](https://docs.valence.desire2learn.com/res/apiprop.html) and [API versions](https://docs.valence.desire2learn.com/basic/version.html). D2L defines product support and component version support separately. A higher latest version does not make a currently supported version deprecated. The checked-in lifecycle snapshot was reviewed 2026-10-11 against [D2L component lifecycle bands](https://docs.valence.desire2learn.com/about.html): LP 1.49+ / LE 1.82+ are listed as oldest fully supported; LP 1.46–1.48 / LE 1.75–1.81 deprecated; LP 1.45 and older / LE 1.74 and older obsolete. No EOL band was separately verified in that component table. D2L’s versioning guidance says deprecated versions have reduced support, obsolete versions may be removed, and EOL contracts are removed. Lifecycle evidence older than 365 days is marked stale and treated as unknown. The application does not scrape docs or detect future changes automatically.

Native checks verify whether the tenant supports configured component versions and report the tenant’s latest version. They do not validate individual endpoint routes, permissions, payloads, response JSON contracts, feature semantics, or user/service-user access. Only the version-check and org-structure route contracts are marked as verified against official documentation; the remaining route contract summaries are derived from source and must be checked against the linked D2L reference before making lifecycle or compatibility claims. Never upgrade production versions automatically; review and test changes first.

## Maintenance rule

Whenever an API call, endpoint path/method, configured API version, minimum-version guard, or request/response contract changes, update `src/apiHealth/endpoints.json`, regenerate/maintain this reference, update `AGENTS.md` and relevant subsystem docs, and extend the endpoint coverage/contract tests. Keep lifecycle claims tied to official D2L sources and a verification date.
